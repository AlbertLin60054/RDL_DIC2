# 強化學習進階作業 (RL Advanced HW - DIC2)

🚀 **Live Demo 線上展示:** [https://AlbertLin60054.github.io/RDL_DIC2/](https://AlbertLin60054.github.io/RDL_DIC2/)

本專案使用純前端 HTML/JavaScript 實作了一個強化的網格地圖開發與 **價值迭代 (Value Iteration)** 演算法展示。這是一份將所有演算法邏輯皆於瀏覽器靜態執行的單頁應用程式，無須依賴任何後端伺服器環境。

## 功能完成事項摘要 (DIC2 要求達成)

### 1. 價值迭代算法 (Value Iteration)
- **算式實現**: 內建了完整的 Value Iteration 數學演算法，採用預設的 Discount Factor $\gamma = 0.9$ 及 Step Reward = -1，反覆跌代運算直到 $\Delta < 10^{-4}$ 為止，精確推導出地圖中每個狀態抵達終點的最佳預期回報。
- **動態推導最佳行動**: 根據求出的價值分數，藉由針對每個格子的四方通道（不含障礙物與邊界）取尋找 $\max_a$，進而精算出 Agent 最理想且最短的前往方向（`↑`、`↓`、`←`、`→`）。

### 2. 最佳政策顯示 (Optimal Policy Visualization)
- 在現有基礎上提供了**兩階段對比**的強大互動按鈕：
  1. 「**1. 產生隨機策略並評估 (Random Policy)**」：維持可以展示初始胡亂指派的情況，讓使用者看見多數隨機行動會陷入迴圈或撞牆 (收斂於 -10)。
  2. 「**2. 執行價值迭代 (Optimal Value Iteration)**」：點擊後，原本畫面上沒系統的亂數方向將自動被演算法推導出來的 **最佳政策 (Optimal Policy)** 全面取代，並主動避開所有自訂的障礙物。
- 所有改變、替換都會無縫且動態地實地反饋更新於畫面上的 `Policy Matrix` 當中。

### 3. 可視化路徑與價值函數分佈
- **更新格子價值 V(s)**：在執行價值迭代找出結果後，畫面下方的 `Value Matrix` 將清楚陳列經過演算法算出的新期盼回報數值，像 `-1.00, -1.90, -2.71` 呈現優美的最短距離梯次漸層。
- **最佳實體路徑高亮畫線 (Path Tracing Highlight)**：針對圖像化視覺顯示的進階要求，演算法不但標示出每個有效格子的方向，更會親自將從 `START` 啟程走到 `END` 的「完整最短路線」挑選出來，並仿照規格書，將沿途路徑以**亮綠色背景**高亮著色，讓使用者能清楚看懂這套演算法規劃的行走軌跡。
